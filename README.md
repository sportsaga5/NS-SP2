Проект реализует Conditional Generative Adversarial Network (cGAN) для генерации рукописных цифр из датасета MNIST с возможностью контроля:
- класса цифры (0-9) — можно указать, какую цифру сгенерировать
- стиля написания (толщина, наклон, почерк) — через интерполяцию латентного пространства# NS-SP2

# Установка зависимостей
pip install -r requirements.txt

# Запуск проекта
python main.py
